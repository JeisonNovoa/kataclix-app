Privacy policy — Kataclix metricas

Last updated: November 18, 2026

Kataclix metricas is a private tool run on the owner's own computer for the owner's own YouTube channels (Kataclix and Causario). It is not a public service and has no other users.

What data it uses

  • The Google sign-in permission (OAuth token) of the channel owner, stored only on the owner's computer.
  • Information about the owner's own channels and videos (titles, publishing status, view counts and YouTube Analytics reports), used only to upload and schedule the owner's videos and to measure how they perform.

What it does not do

  • It does not collect data from viewers or any other person.
  • It does not sell, share or transfer any data to third parties, and does not use it for advertising.
  • It does not store data on any server: everything stays on the owner's computer.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Removing access

Access can be revoked at any time from the Google account security settings (https://myaccount.google.com/permissions). Deleting the token file on the owner's computer also removes it.
