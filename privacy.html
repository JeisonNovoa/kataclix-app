Privacy policy — Kataclix metricas

Last updated: November 21, 2026

Kataclix metricas (and its Meta app «Publicador Canales») is a private tool run on the owner's own computer for the owner's own YouTube channels and Facebook Pages (Kataclix, Causario and Entre el Cielo y el Misterio). It is not a public service and has no other users.

What data it uses

  • The Google sign-in permission (OAuth token) of the channel owner, stored only on the owner's computer.
  • Information about the owner's own channels and videos (titles, publishing status, view counts and YouTube Analytics reports), used only to upload and schedule the owner's videos and to measure how they perform.
  • The Facebook Page access tokens of the Page owner, stored only on the owner's computer.
  • Information about the owner's own Facebook Pages and Reels (publishing status, Page and video insights such as plays, reach, watch time, reactions, shares and follows) and the public comments people leave on those Reels, used only to publish the owner's videos and to understand, in aggregate, how they perform.

What it does not do

  • It does not collect data from viewers beyond the public comments and aggregate statistics of the owner's own Pages and channels, and it never contacts them.
  • It does not sell, share or transfer any data to third parties, and does not use it for advertising.
  • It does not store data on any server: everything stays on the owner's computer.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

Meta Platform

This tool uses the Meta Graph API only on Pages the owner manages. Meta's practices are described in the Meta Privacy Policy.

Removing access and deleting data

Access can be revoked at any time from the Google account security settings (https://myaccount.google.com/permissions). Deleting the token file on the owner's computer also removes it. For Facebook, remove the app from Facebook Settings → Business integrations and write to the contact address below: all stored data (tokens, statistics and comments) is deleted from the owner's computer within 7 days.
